# The Harness ships its own browser server

Browser-driving subagents need a fixed `tools:` allowlist, and MCP tool names depend on what the user named their server, so the Harness declares its own `chrome-devtools-mcp` server in the plugin's `.mcp.json`, giving stable plugin-namespaced tool names. It runs against a dedicated persistent profile directory so the user signs in once and verification can reach authenticated pages; pages open in the background so the browser never steals focus. We rejected depending on Google's chrome-devtools plugin (default, signed-out profile) and inheriting whatever browser MCP the user has (no stable allowlist).
