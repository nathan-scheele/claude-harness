Set up the harness for this repo. Things you won't find in the repo: we squash-merge, and merging to main deploys to production at https://notes.example.com through the Deploy workflow. Our only sandbox is staging at https://staging.notes.example.com. Test fixtures are JSON files in test/fixtures/, and `git checkout -- test/fixtures` resets them. There are no data connectors. Issues close with `Closes #<n>` in the PR body.
